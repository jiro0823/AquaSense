# AquaSense Integration Review

Trace only the cross-layer path affected by the requested change or failure.
Check contracts, units, conversions, stale/invalid data handling, recovery, and
relevant tests as applicable. Distinguish dashboard controls, backend command
support, firmware behavior, configuration/commissioning, and verified physical
operation. Code or an acknowledgement alone does not prove physical actuation.

Report only evidence-backed findings, label confidence and severity, explain
impact, and suggest focused verification. For a full or system-wide audit, use
the `system-auditor` skill.
